# ЛИС и АНГЕЛ

Двухмерный платформер о лисе и ангеле. Одиннадцать глав, разломы, меняющие
гравитацию, и финальная сцена.

**Играть:** https://humass67.github.io/lis-i-angel/

## Управление

| Клавиша | Действие |
|---|---|
| ← → | ходьба |
| SPACE | прыжок |
| E | крик |
| ESC | меню |
| P | консоль (для отладки) |

## Что это за репозиторий

Здесь лежит только собранная игра — то, что видит браузер:
`index.html`, `styles.css`, `js/` и `assets/`.

Исходники разработки (тесты, инструменты, документы) хранятся отдельно.

## Как обновить игру

В рабочей папке проекта:

```bash
python -I tools/publish_site.py --push
```

Команда соберёт сайт заново и отправит изменения на GitHub. Через минуту
обновление появится на сайте.

Проверить локально перед публикацией:

```bash
python -I tools/publish_site.py
cd ../lis-i-angel-site
python -m http.server 8123
```

и открыть http://127.0.0.1:8123 — по этому адресу всё работает так же,
как на GitHub Pages.

## Технические заметки

- Игра полностью статическая: ни сервера, ни базы данных, ни сборки.
- Прогресс сохраняется в `localStorage` браузера — у каждого игрока свой.
- Файл `.nojekyll` нужен, чтобы GitHub Pages не прогонял сайт через Jekyll.
- Пути к ресурсам относительные, поэтому игра работает и в подпапке
  (`/имя-репозитория/`), а не только в корне домена.
